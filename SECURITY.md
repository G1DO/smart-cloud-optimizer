# Vulnerability reporting

This application is a local research/demo build. Its
[current security boundaries](docs/security/README.md) include trust-based HTTP
identity and plaintext credential storage; it is not suitable for public or
multi-tenant deployment.

GitHub private vulnerability reporting is not currently enabled for this
repository, and no dedicated private contact is published. Request a private
reporting channel from the [repository maintainer](https://github.com/G1DO).
If a public issue is the only available contact route, include only the request
for a private channel, without vulnerability details, credentials, personal data,
or an exploit. Share the affected revision, impact, and minimal reproduction
privately once a channel is established.

Changes to the private reporting route should update this file. The repository
does not currently declare a security support window or response-time commitment.
