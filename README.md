# CCPE reproducibility artifact

Empirical evidence for *The Price of Conservatism in Cloud Optimization: An
Empirical Evaluation of Right-Sizing and Reservation Policies* (CCPE submission).

This public release branch contains the paper scripts, sanitized synthetic
database, and supporting modules (`optimizer/`, `ml_engine/`, `storage/`) needed
to reproduce all reported experiments. It does **not** include the application
UI (Streamlit/Next.js) or live AWS collection tooling.
