# Smart Cloud Optimizer — CCPE software release

Public reproducibility artifact for *The Price of Conservatism in Cloud
Optimization: An Empirical Evaluation of Right-Sizing and Reservation
Policies* (CCPE Research Article submission).

This branch ships the **implemented optimization stack** and a **sanitized
synthetic database**. It does **not** include the manuscript (`paper/`),
internal docs (`docs/`), UI, or live AWS tooling.
